# Cortex — public demo

A read-only demo of [Cortex](https://github.com/ALTERLK/cortex): ask
questions over the FastAPI and uv documentation plus four papers, and
inspect the passages, ranks, and cost behind each answer.

This Space is rate-limited and has a daily request budget. Uploading
documents is disabled here; run the project locally to index your own.
